# Rshot

Rshot 是一个用 Rust 和 GPUI 编写的截图与贴图应用。当前版本面向 macOS 14 及以上。PixPin 3.6.6.0 的功能、平台差异和实现目标记录在 [PixPin 功能清单](docs/pixpin.md)。

## 运行

需要 Rust、Cargo 和 macOS Command Line Tools。在项目目录执行 `cargo run --locked -p rshot-gui`。

1. 点击「区域截图」。悬停可预览最前方窗口或 macOS 顶部菜单栏，未命中时预览当前显示器全屏。单击确认候选区域，拖动可自由框选。首次截图时 macOS 会请求屏幕录制授权。请按照系统提示授权，再退出并重新启动 Rshot。
2. 选好区域后，点击「编辑」或按 `E` 进入截图编辑器。也可直接复制到剪贴板、保存 PNG 或置顶贴图，对应 `Enter` 或 `⌘C`、`⌘S`、`⌘P`。`Esc` 退出截图。
3. 主窗口的「贴出剪贴板」支持图片和纯文本。拖动贴图标题栏移动窗口，滚轮缩放图片，`Esc` 或 `⌘W` 关闭当前贴图。

## 截图标注

- **箭头**：从箭尾拖到指向的位置。
- **文字**：点击图片选择位置，输入内容后确认。文字支持中文和自动换行。
- **马赛克**：拖出要处理的矩形区域。

使用「撤销」「重做」或 `⌘Z`、`⌘⇧Z` 调整标注。完成后点击「复制」或「保存 PNG」，也可按 `⌘C` 或 `⌘S`。输出保留截图的原始像素尺寸，并包含当前所有标注。

## 长截图

1. 选中一个矩形区域，点击「纵向长截图」或「横向长截图」。
2. 在原窗口滚动一小段，保留至少约三分之一的重叠区域，再点击预览窗里的「添加一帧」。可拖动预览窗避开需要滚动的内容。
3. 重复采集直到覆盖所需范围，然后点击「复制」或「保存 PNG」。结果上限为 6400 万像素。

如果出现匹配失败，回到上一次成功采集的位置，再小幅滚动。长截图使用手动逐帧采集。窗口选择以当前显示器上的窗口矩形为准。跨屏选区、控件级识别、全局热键、其余标注工具、OCR 与录屏见功能清单。

`cargo test --locked --workspace` 检查标注合成、撤销重做、PNG 往返、Retina 裁切与编辑坐标、负坐标显示器上的窗口裁切、颜色转换，以及长图的横纵方向、固定页眉页脚、反向滚动、重复内容和匹配失败后恢复。
