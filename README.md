# Rshot

Rshot 是一个用 Rust 和 GPUI 编写的截图与贴图应用。当前版本面向 macOS 14 及以上。PixPin 3.6.6.0 的功能、平台差异和实现目标记录在 [PixPin 功能清单](docs/pixpin.md)。

## 运行

需要 Rust、Cargo 和 macOS Command Line Tools。在项目目录执行 `cargo run --locked`。

1. 点击「区域截图」。鼠标悬停可预览当前显示器上的窗口区域，单击选中窗口，拖动可自由框选。首次截图时 macOS 会请求屏幕录制授权。请按照系统提示授权，再退出并重新启动 Rshot。
2. 选好区域后，可以复制到剪贴板、用系统对话框保存 PNG，或将区域放到一个置顶窗口中。快捷键为 `Enter` 或 `⌘C`、`⌘S`、`⌘P`。`Esc` 退出截图。
3. 主窗口的「贴出剪贴板」支持图片和纯文本。拖动贴图标题栏移动窗口，滚轮缩放图片，`Esc` 或 `⌘W` 关闭当前贴图。

## 长截图

1. 选中一个矩形区域，点击「纵向长截图」或「横向长截图」。
2. 在原窗口滚动一小段，保留至少约三分之一的重叠区域，再点击预览窗里的「添加一帧」。可拖动预览窗避开需要滚动的内容。
3. 重复采集直到覆盖所需范围，然后点击「复制」或「保存 PNG」。结果上限为 6400 万像素。

如果出现匹配失败，回到上一次成功采集的位置，再小幅滚动。长截图使用手动逐帧采集。窗口选择以当前显示器上的窗口矩形为准。跨屏选区、控件级识别、全局热键、标注、OCR 与录屏见功能清单。

`cargo test --locked` 检查 Retina 裁切、负坐标显示器上的窗口裁切、颜色转换、PNG 往返，以及长图的横纵方向、固定页眉页脚、反向滚动、重复内容和匹配失败后恢复。
